# brickarc website

## Intro
This app is a website of affiliated marketing promoting LEGO sets.

## Home page structure
Home page should contain:

- Header with website title "BrickArc" and search area - should be sticky
- Body containing in huge font the text: "You can find here amazing LEGO sets of architecture landmarks around the globe in affordable price"
- Footer with "All rights reserved" and current year

## Products page
- This page should contain all promoted products with card contains small image and name
- Every product card should link to product page

## Product page
This page should contain:
- product name
- product images (product box, model and real landmark)
- product description (details about when wlandmark was founded, history etc.)
